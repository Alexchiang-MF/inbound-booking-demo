# 進貨預約排程台 — 流程討論用 Demo

供應商以**採購單號**進入預約、依車輛噸數挑選剩餘時段的進貨預約流程示範。單一 HTML 檔，無後端、無安裝，開啟即可操作。

**線上操作：** https://alexchiang-mf.github.io/inbound-booking-demo/

> ⚠️ 本專案為流程討論用的示範系統。**所有廠商名稱、採購單號、車牌與統計數據皆為虛構**，與任何實際公司或營運數據無關；碼頭數量與時段設定僅為說明用的預設值。

## 這個 Demo 想驗證什麼

| 畫面 | 角色 | 內容 |
|---|---|---|
| 採購單預約 | 廠商 | 輸入單號 → 選噸數 → 點剩餘時段 → 產生預約號碼與 QRcode |
| 預約查詢 | 廠商 | 以單號查詢自己那張單的預約狀態與排隊進度 |
| 修改預約 | 廠商 | 三步驟改約流程，含變更對照與預約號碼換發提示 |
| 警衛室過刷 | 警衛 | 報到、進場、離場、判定過號、放行下一位遞補 |
| 碼頭看板 | 現場 | 碼頭即時佔用、排隊順序、預估進場與等待時間 |
| 到場準點報表 | 採購／管理 | 廠商別準點統計，可匯出 CSV |
| 參數設定 | 管理 | 碼頭啟用、開放時段、每小時切分、下貨工時 |
| 規格與待確認 | — | 已定規則、待拍板事項、操作手順 |

## 核心規則

1. **採購單號是預約 key。** 有下採購單才拿得到單號，進貨日與收貨倉別由採購單決定，廠商不能自行挑日期。
2. **餐廳訂位式選時段。** 先選車輛噸數，系統只列出還有空位的時段。
3. **噸數決定佔用格數。** 11 噸以下 1 格、11 噸以上 2 格、鷗翼車 2 格且停靠廣場。
4. **先搶先贏。** 進貨日當天之前可改約或取消，改約依當下剩餘時段重新挑選。
5. **等待時間 = 前車預估離場 + 15 分緩衝。** 叫號後 15 分未進場判定過號，由警衛室放行下一位提早進廠。
6. **No-show 只做統計。** 供採購與廠商檢討，不擋預約權限；準時與提早遞補進場同樣入帳。
7. **廠商只看得到自己的單。** 廠商端沒有預約總覽，必須輸入採購單號才查得到。

## 怎麼試

右上角有模擬時鐘，按「＋15 分」可推進時間。建議順序：

1. **採購單預約** 挑一張單，切換車型看時段格數變化（大車會吃掉兩格）。
2. **警衛室過刷** 輸入未報到清單中的號碼完成報到。
3. **碼頭看板** 對排隊車輛按「叫號指派」，再回警衛室做進場過刷。
4. 按 **＋15 分** 推進時間，看叫號逾時如何轉為過號、以及後車遞補。
5. **參數設定** 關掉一個碼頭或改切分段數，回預約頁看剩餘席位如何連動。

資料存在各自瀏覽器本機，互不影響；要回到初始狀態按右上「重設 Demo 資料」。

## 技術

單一 HTML 檔，無框架、無建置流程。QRcode 產生器（[qrcodejs](https://github.com/davidshimjs/qrcodejs)，MIT）已內嵌，離線亦可運作；字型透過 Google Fonts 載入，載入失敗時自動退回系統字型，不影響功能。
